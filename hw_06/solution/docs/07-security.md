# 7. Безопасность

| Область | Решение |
|---|---|
| Аутентификация и авторизация | JWT, проверяется на API Gateway; OAuth2/OIDC для клиентов; ролевая модель (покупатель, продавец, модератор) |
| Шифрование | TLS 1.2+ на всех соединениях; шифрование данных at rest (MongoDB, S3) |
| Секреты | Vault / Cloud KMS, регулярная ротация ключей |
| Защита периметра | CDN, WAF, rate limiting на шлюзе, CAPTCHA для подозрительной активности (DDoS, боты) |
| Платежи | Idempotency-Key, неизменяемый Payment Status Log, проверка вебхуков провайдера |
| Загрузка файлов | Ресайз в отдельном сервисе (Image Resizer) с ограничением размера ≤ 1 МБ |

**Известные доработки:** выпуск JWT (Identity Provider / Auth Service) на диаграмме не показан — добавить как отдельный сервис или managed IdP; отдельный WAF-узел перед шлюзом на диаграмме не нарисован.
