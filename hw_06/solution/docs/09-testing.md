# 9. Тестирование

## 9.1 Нагрузочное тестирование

- Инструмент: k6 или Gatling.
- Постепенный ramp-up до 5 000 RPS чтения и 50 RPS записи.
- Сценарии: read-heavy baseline, поисковый burst, всплеск заказов.
- Проверка SLO под нагрузкой: p99 поиска < 200 мс.
- Отдельный прогон: пиковая одновременная загрузка фото.
- Результаты уточняют допущения сайзинга (RPS на экземпляр, размер ответа, доля просмотров фото).

## 9.2 Chaos-эксперименты

| Эксперимент | Ожидаемое поведение |
|---|---|
| Отключение MongoDB primary | Автоматический failover |
| Падение ноды Elasticsearch | Деградация, а не отказ |
| Обрыв Kafka broker | Репликация, DLQ |
| Таймаут Payment Provider | Срабатывает Circuit Breaker |
| Потеря Redis | Graceful degradation кэша и чата |
| Сетевой сплит между зонами | Система продолжает работать в остатке зон |
