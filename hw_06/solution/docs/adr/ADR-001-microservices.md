# ADR-001: Микросервисы с событийной интеграцией вместо монолита

- **Статус:** Принято
- **Контекст:** 10 млн DAU, 100 млн активных объявлений, read:write = 100:1, разные SLA на разные операции (поиск p99 < 200 мс, запись < 50 RPS).
- **Решение:** Декомпозировать систему на независимые сервисы по доменам (Advert, Search, Chat, Review, Order, Delivery, Moderation), интегрированные через Kafka для асинхронных сценариев и через API Gateway — для синхронных.
- **Альтернативы:** Монолит (отклонён — не даёт независимого масштабирования hot-path'ов); Modular monolith (отклонён — усложняет полиглот-персистентность и изоляцию отказов внешних интеграций).
- **Последствия:** (+) независимое масштабирование и деплой, изоляция отказов; (−) операционная сложность, distributed tracing и мониторинг обязательны, eventual consistency между сервисами.
