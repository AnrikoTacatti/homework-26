# 1. Требования

Проект: **сервис объявлений с доставкой** (класс Avito: классифайд + доставка).

## 1.1 Функциональные требования (scope)

| № | Функция | Описание |
|---|---|---|
| 1 | Объявления | Создание, чтение, обновление, удаление (CRUD): текст, цена, категория, локация, фотографии |
| 2 | Поиск и фильтрация | По категории, локации, цене |
| 3 | Просмотр | Карточка объявления |
| 4 | Авторизация | Регистрация и вход пользователей |
| 5 | Чат | Переписка покупатель ↔ продавец |
| 6 | Отзывы | Рейтинги и отзывы после сделки |
| 7 | Оплата | Через внешний Payment Provider |
| 8 | Доставка | Через внешний Delivery Provider |
| 9 | Модерация | Проверка объявлений перед публикацией |
| 10 | Фото | Ресайз в 3 размера, размер файла ≤ 1 МБ |

## 1.2 Нефункциональные требования

| Параметр | Значение |
|---|---|
| DAU | 10 млн |
| Активных объявлений | 100 млн |
| Соотношение read : write | 100 : 1 |
| Пик чтения | 5 000 RPS |
| Пик записи | < 50 RPS |
| Поиск | p99 < 200 мс |
| Доступность | 99,9 % (≈ 8,8 ч простоя в год) |
| Консистентность | строгая не требуется (eventual допустима) |
| География | стабильная работа в разных гео-точках (обеспечиваем через CDN; сервисы — в одном основном регионе) |

## 1.3 Риски

| Риск | Последствие | Как снижаем |
|---|---|---|
| Пиковая нагрузка на поиск | p99 может превысить 200 мс | Elasticsearch + Redis + горизонтальное масштабирование Search Service |
| Недоступность MongoDB | нельзя создавать/изменять объявления | Replica Set, backup, автоматический failover |
| Недоступность Elasticsearch | поиск недоступен или устарел | MongoDB — source of truth, восстановление индекса из БД/событий |
| Потеря/задержка Kafka-событий | индекс не сразу актуален | replication, retry, DLQ, мониторинг consumer lag |
| Cache stampede | рост нагрузки на MongoDB | TTL + request coalescing / distributed lock |
| Недоступность Delivery Provider | нельзя создать доставку | timeout + retry + Circuit Breaker |
| Недоступность Payment Provider | заказ не оплатить | idempotency + retry + Circuit Breaker |
| DDoS / боты | исчерпание ресурсов | CDN, WAF, rate limiting, CAPTCHA для подозрительной активности |

## 1.4 Ограничения

- Один основной регион.
- Active-Active между регионами не реализуем.
- Payment и Delivery — внешние системы.
- ML-модерация вне scope.
- Мобильные приложения вне scope.

## 1.5 Backlog (вне scope)

Рекомендации · рекламная платформа · программа лояльности · аукционы · международная доставка · мобильное приложение.

> Backlog — осознанный список того, что **не** делаем в этой версии. Архитектура не обязана это поддерживать, но и не закрывает путь (например, рекомендации можно добавить отдельным consumer'ом Kafka).
